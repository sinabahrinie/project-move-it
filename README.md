# Move It – Moving & Transportation Website

## About the Project

**Move It** is a modern website designed for a professional moving and transportation company. It showcases the company's services and highlights its commitment to providing reliable, safe, and stress-free moving experiences.

The website features a clean layout, responsive navigation, service sections, and an image carousel to create an engaging user experience.

## Features

- Responsive navigation bar
- Modern hero section with a call-to-action
- Three service highlights:
  - Professional Moving Services
  - Countrywide Transportation
  - Personal Touch
- Bootstrap image carousel
- Responsive footer
- Dark theme using Bootstrap 5

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
